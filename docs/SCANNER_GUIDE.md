# Content scanner guide\n\nThe scanner checks the subject folders under `content/` and creates `assets/data/content-index.json`. It currently indexes PDF, Markdown and TXT files. README files are ignored.\n\nRun:\n\n```bash\npython tools/scan-content.py\npython tools/validate-index.py\n```\n\nUse only material you have permission to publish. Keep large PDFs optimized and use clear file names. Video links and external URLs can be added manually to the JSON index using type `Video` or `Link`.
