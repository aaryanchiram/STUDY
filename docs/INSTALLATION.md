# Installation and local preview\n\nRequirements: a modern browser and Python 3 (only needed for the content scanner/local server).\n\n1. Clone or download this repository.\n2. Open a terminal in the repository root.\n3. Run `python -m http.server 8000`.\n4. Visit `http://localhost:8000`.\n\nDo not open index.html directly with file:// because browser fetch requests for JSON may be blocked. For GitHub Pages, select the main branch and root folder in repository Settings → Pages.
