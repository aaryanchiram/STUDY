# CTET Digital Library — परिचय\n\nयह STUDY रिपॉजिटरी में बनाई जा रही विषयवार डिजिटल लाइब्रेरी है। इसमें CDP, हिंदी, संस्कृत और सामाजिक विज्ञान की PDF/नोट्स/वीडियो लिंक व्यवस्थित रूप से दिखाए जाएँगे।\n\n## वेबसाइट चलाना\n\nGitHub Pages या किसी static hosting पर रिपॉजिटरी प्रकाशित करें। लोकल टेस्ट के लिए Python उपलब्ध हो तो रिपॉजिटरी रूट में चलाएँ:\n\n```bash\npython -m http.server 8000\n```\n\nफिर `http://localhost:8000` खोलें।\n\n## सामग्री जोड़ना\n\n1. सही विषय के `content/` फ़ोल्डर में PDF/MD/TXT फ़ाइल रखें।\n2. फ़ाइल का नाम छोटा और अर्थपूर्ण रखें।\n3. `python tools/scan-content.py` चलाएँ।\n4. `python tools/validate-index.py` से इंडेक्स जाँचें।\n5. बदलाव GitHub पर commit करें।\n\n## विषय फ़ोल्डर\n\n- `content/CDP/` — बाल विकास एवं शिक्षाशास्त्र\n- `content/Hindi/` — हिंदी भाषा\n- `content/Sanskrit/` — संस्कृत भाषा\n- `content/Social_Science/` — सामाजिक विज्ञान\n- `content/Common/` — सामान्य सामग्री\n\nफिलहाल इंडेक्स में मौजूद चार प्रविष्टियाँ केवल डेमो हैं; वास्तविक अध्ययन सामग्री अलग से जोड़ी जाएगी।
